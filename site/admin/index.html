    Tasa del día

    La carta está en dólares y la web muestra el equivalente en bolívares. Si la consulta falla se usa la última tasa conocida; nunca se inventa una.

    Envío por distancia

    Precios en dólares. Un anillo sin precio se muestra como «por confirmar»; más allá del máximo, la web no deja pedir delivery.

    Datos de pago

    Solo se le ofrecen al cliente los métodos con todos sus datos rellenos. Mientras estén vacíos, la web pide los datos por WhatsApp en lugar de enseñar nada inventado.

    Aviso interno

    Esto importa. El pedido se manda aquí en cuanto el cliente marca que pagó, antes de abrir WhatsApp. Es la red de seguridad para quien paga y no llega a enviar el mensaje. Sin esta dirección, ese caso se pierde: un sitio sin servidor no puede avisar por su cuenta.
